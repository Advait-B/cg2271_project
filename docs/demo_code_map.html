Why each board (justification)Joystick, button and sound sit on the MCXC444, which runs the session logic. The EC11 sits on the ESP because the ESP32 sends the volume keys over USB HID (pollEncoder 371, pressVolume 365).

Polling and interrupts (2 marks)

Polled sensorMCX joystickTask 564–579: reads the ADC (readJoystick 301) every 20 ms via vTaskDelay 577. Also ESP encoder push switch, polled and debounced in pollEncoder.
Interrupt sensorMCX initInputs 315–322 sets IRQC to either edge and enables PORTA in the NVIC; handled in PORTA_IRQHandler 325. NVIC levels: PORTA 1, UART2 2 (47–48). Also ESP encoderIsr 349, attached at 361–362.

ISR design (3 marks)

Button / sound ISRMCX PORTA_IRQHandler 325–350: only reads the tick, debounces, then xQueueSendFromISR (337, 345) and portYIELD_FROM_ISR 349.
UART ISR, never waits for inputMCX UART2_FLEXIO_IRQHandler 372–396: handles one byte per interrupt. TX: next byte, then xSemaphoreGiveFromISR(txDoneSem) 382. RX: collects a 5-byte frame and hands it over with xQueueSendFromISR(rxQueue) 391. The checksum check is in a task (641).
